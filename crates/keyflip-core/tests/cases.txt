# keyflip acceptance cases (machine readable; owner: specs/001-mixed-input/acceptance.md)
#
# Format: id <TAB> keys <TAB> expected total committed text
#
# Key notation (standard zhuyin layout, US keyboard):
#   a-z 0-9 , . ; / - '   the physical key, no Shift
#   A-Z                   Shift + that letter
#   ~ ! @ # $ % ^ & * ( ) + { } | : " ?   Shift + the key that types them
#   <S-k>                 Shift + plain key k, e.g. <S--> types _
#   _                     space bar
#   <E> Enter   <T> Tab   <L> Left   <R> Right   <D> Down   <B> Backspace
#   <S-E>                 Shift + Enter   <S-_> Shift + Space (full-width toggle)
# Expected is the concatenation of everything the engine committed.
# {sp} stands for a space (trailing spaces are easy to lose in editors).
